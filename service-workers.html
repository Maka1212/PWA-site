Service Workers

Service Worker — это скрипт, который работает в фоне. Он кэширует файлы, перехватывает запросы и позволяет приложению работать без интернета.

Что умеет Service Worker

  • Кэшировать HTML, CSS, JS и картинки
  • Перехватывать сетевые запросы
  • Работать офлайн
  • Принимать push-уведомления
  • Синхронизировать данные при возврате в онлайн

Пример регистрации

if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js')
    .then(() => console.log('SW зарегистрирован'))
    .catch(err => console.error('Ошибка:', err));
}
