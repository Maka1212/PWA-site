Web App Manifest

Файл, который описывает установленное приложение

Manifest — это файл manifest.json. Он описывает, как приложение выглядит после установки.

Что содержит манифест

Поле Назначение
nameПолное название
short_nameКороткое название под иконкой
iconsНабор иконок разных размеров
start_urlСтартовая страница
displayРежим отображения (standalone, fullscreen)
theme_colorЦвет верхней панели
background_colorЦвет фона при запуске

Пример manifest.json

{
  "name": "PWA Info",
  "short_name": "PWA",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#0074d9",
  "icons": [
    { "src": "/img/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/img/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}

Как подключить

Внутри тега <head> добавьте:

<link rel="manifest" href="manifest.json">
