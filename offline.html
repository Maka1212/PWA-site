Работа офлайн

Как PWA живёт без интернета

PWA продолжает работать без сети — пользователь видит интерфейс, может открывать сохранённые страницы и получает данные из кэша.

Что доступно офлайн

  • Интерфейс приложения
  • Ранее открытые страницы
  • Ранее загруженные изображения
  • Формы (отправятся при возврате в онлайн)

Что недоступно

  • Новые данные с сервера
  • Отправка push-уведомлений
  • Актуальная информация из API

Как это устроено

Service Worker отдаёт заранее сохранённые файлы, когда сеть недоступна. Пользователь даже не замечает, что интернет пропал.
